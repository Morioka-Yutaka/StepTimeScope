# The `StepTimeScope` package, version: `0.1.0`;
  
---
 
StepTimeScope is a lightweight SAS package for reviewing relative processing time across DATA and PROC steps. It records elapsed-time information with PROC SCAPROC, produces a concise step-level table, and can create a chart to surface potential hotspots. It is designed for quick performance checks and comparisons—not real-time monitoring or precise benchmarking.

## `%timer_end()` macro <a name="timerend-macro-1"></a> ######

Macro:       timer_end  

Purpose:     Stops elapsed-time collection, creates a step-level  
               summary table, and optionally produces a bar chart.  
  
Parameter:   plot=  
                 Y : Creates a processing-time bar chart (default).  
                 N : Creates the summary table only.  
  
Output:      WORK.SCAPROC_ELAPSED  
               Contains step number, process type, elapsed time in  
               milliseconds, and elapsed time in seconds.  
  
Generation:  The output data set is created with GENMAX=100.  
               When %timer_start() and %timer_end() are run repeatedly  
               in the same SAS session, up to 100 previous results are  
               retained as generation data sets.
  
Notes:       Intended for relative performance checks and hotspot  
               identification. It is not a real-time monitoring or  
               precise benchmarking tool.  
  
Example Usage:  
%timer_start();  
data work.class_bmi;  
  set sashelp.class;  
  bmi = weight / (height ** 2) * 703;  
run;  

proc sort data=work.class_bmi out=work.class_bmi_sort;  
  by age sex;  
run;  

proc means data=work.class_bmi_sort n mean min max;  
  var age height weight bmi;  
run;  
  
%timer_end();  
  
Requires:    %timer_start() must be run before this macro.

## `%timer_start()` macro <a name="timerstart-macro-2"></a> ######

Macro:       timer_start  

Purpose:     Starts step-level elapsed-time collection for relative  
               performance review of subsequent DATA and PROC steps.  

Notes:       Uses PROC SCAPROC to record processing metadata in a  
               temporary file under the WORK directory. FULLSTIMER is  
               enabled for supplemental information in the SAS log.  

Example Usage:  
%timer_start();  
data work.class_bmi;  
  set sashelp.class;  
  bmi = weight / (height ** 2) * 703;  
run;  

proc sort data=work.class_bmi out=work.class_bmi_sort;  
  by age sex;  
run;  

proc means data=work.class_bmi_sort n mean min max;  
  var age height weight bmi;  
run;  

%timer_end();  


See also:    %timer_end()
